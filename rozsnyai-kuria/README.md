## Tőlük kell

1. 8–12 saját fotó: kúria kívülről, pince, terített esküvői asztal, szobák, wellness, borok.
2. Valódi árak és csomagok (esküvő, rendezvény, szállás, kóstoló). Az `arak.txt`-be maguk is beírhatják.
3. Esküvői befogadóképesség (ültetett vacsora a pincében / teremben / teraszon), szobák száma.
4. Megerősítés: Alsópincesor u. 4. a helyes cím? Melyik telefonszám legyen elöl?
5. Van-e Facebook/Instagram oldaluk, logójuk.
6. Domain: rozsnyaikuria.hu marad, HTTPS-sel; a régi `/wp/` oldalt kiváltja.

## Árlista

`arak.txt`: `## csoport`, `név | ár`, `> megjegyzés`, `# komment`. Az oldal futás közben
betölti (`assets/price-parse.js`). Ugyanez be van égetve az `index.html`-be az
`arak:start/end` jelölők közé (`node tools/bake.mjs`), így JavaScript nélkül is működik.
Hibás fájlnál a beégetett lista marad.

## Dizájn

Pinceszín bordó-fekete (`#2E1419`), elefántcsont (`#FBF7F1`), mély borvörös (`#6B2233`),
aszú-arany (`#D9B878` sötéten, `#85601F` világoson). Cormorant Garamond címek, Nunito Sans
szöveg, saját tárhelyen (`assets/fonts.css`, a sminktetovalas-tatabanya és a
gloriett-fejlesztohaz demóból átvéve). Egyetlen díszítés: két egymásba fonódó gyűrű
(logó, kártyák, kapcsolat, favicon). A fotókeretek szaggatott kerete mögött vékony belső
keret van, mint egy paszpartu; a hero fotója felül íves, mint a pince boltíve.

## Fájlok

```
index.html            egyoldalas oldal; az árak az arak:start/end jelölők között
arak.txt              árlista és csomagok (PÉLDA összegek!)
styles.css            tokenek, elrendezés, töréspontok
script.js             árbetöltő, menü, reveal
assets/               fonts.css + fonts/, favicon.svg, price-parse.js
tools/bake.mjs        arak.txt beégetése az index.html-be
tools/shoot.mjs       képernyőképek (BASE_URL)
tools/deliver.mjs     átadási képek (BASE_URL); a mobil két hasábra hajtva
```

Futtatás: `python3 -m http.server 8195 -d rozsnyai-kuria`, majd a mappában
`node tools/shoot.mjs` és `node tools/deliver.mjs`.
Ellenőrizve 320–1440 px között: nincs vízszintes görgetés.
